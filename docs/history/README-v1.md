# LASE 3D Viewer

Портативная программа на C++17 для Windows 10/11. Установка, права администратора, Python, Qt и Visual C++ Redistributable не нужны. Используются системные Win32, UCRT и OpenGL, входящие в Windows 10/11.

## Портативный запуск

- `Lase3DViewer-Portable.exe` — сборка x86 для Windows 10 (32/64 бита) и Windows 11 на процессорах Intel/AMD. Можно скопировать только этот EXE в любую папку или на флешку.
- `Lase3DViewer.exe` — сборка x64 для 64-битной Windows; предпочтительна для больших файлов благодаря большему доступному адресному пространству.
- `Lase3DViewer-Portable-Windows.zip` — комплект обеих сборок и инструкции. Распакуйте архив перед запуском.

Программа не требует файлов рядом с EXE, не хранит настройки в реестре и не обращается к сети. При обычном запуске файлы создаются только при выбранном пользователем экспорте. BIN выбирается в программе из любого доступного каталога. Предыдущие пути к сканам не зашиты в EXE.

Обе сборки проверены на текущей Windows в отдельной временной папке, с кириллицей и пробелами в путях, без каталога компилятора в PATH: чтение BIN, отрисовка точек/поверхности и экспорт PLY прошли. Отдельная чистая установка каждой версии Windows и Windows ARM не тестировались. Linux/macOS и Windows 7/8 в эту поставку не входят.

## Интерфейс

Тёмное оформление с бирюзовым акцентом, стартовый экран с подсказкой открытия файла, переключатели точек/поверхности, ракурсов и наборов данных. Недоступные команды отключены. Вверху отображаются имя файла и тип скана; под моделью — размеры, шкала высоты и управление мышью. Кнопка экспорта закреплена снизу. В компактном окне карточка статистики скрывается, чтобы сохранить доступ ко всем кнопкам. Поддерживаются Tab и клавиатурные сочетания. Интерфейс нарисован средствами Windows и не требует дополнительных файлов.

Проверены собственные отрисовки интерфейса в обычном и компактном окне, стартовый экран и оба режима OpenGL в x86/x64. Проверка выполнена на Reference Cat22 с исходным путём на кириллице.

## Отображение

Стиль по образцам LASE: чистый чёрный фон, точки 1 пиксель без сглаживания, цвет по высоте Z (синий → голубой → зелёный → жёлтый → красный). Шкала нормируется по минимальной и максимальной высоте текущего файла. Сетка и оси по умолчанию скрыты; их можно включить на левой панели. Зелёная надпись показывает номер, тип скана и количество точек. Дата и время не выводятся, поскольку их декодирование из BIN не подтверждено.

## Использование

1. Нажмите **Открыть файл** и выберите файл. Можно перетащить BIN в окно или передать путь первым аргументом EXE.
2. **Точки** показывает исходные XYZ, **Поверхность** — приближённые треугольники с исходными точками.
3. Левая кнопка мыши вращает модель, правая или средняя перемещает, колесо меняет масштаб. Кнопка **Общий вид** возвращает исходный ракурс. Есть виды сверху, спереди и сбоку.
4. На левой панели можно включить координатную сетку и изменить размер точек кнопками − и +.
5. **Экспортировать PLY** сохраняет точки с цветами, а в режиме поверхности также грани. Экспорт сохраняет координаты файла без масштабирования и преобразования осей.

При фокусе в 3D-области: `R` или `Home` — сброс, `1` — точки, `2` — поверхность, `Ctrl+O` — открыть, `Ctrl+S` — экспорт.

## Поддерживаемый формат и ограничения

BIN — общее расширение, не единый формат. Чтение разработано по фактической структуре предоставленного `0000015068_Full.bin` и проверено на четырёх локальных Full/Empty-файлах LASE с номерами 15068 и 15069, а также на 0000000413_Full.bin (БелАЗ 49) и 0000000418_Full.bin (Cat7). Официальная спецификация формата не предоставлена; совместимость с другими версиями LASE не гарантируется. Несовпадающая структура, обрезанные записи и лишние данные вызывают сообщение об ошибке.

Парсер читает заголовок, строки с однобайтовой длиной, записи о фотографиях и группы профилей переменной длины. Пути фотографий внутри BIN не открываются. Поддерживаются оба проверенных варианта заголовка (1,2) и (0,1). Группы профилей проверяются отдельно и не смешиваются. Для новых файлов БелАЗ 49 и Cat7 по умолчанию отображается пространственный набор типа 1; кнопками «Набор 1» и «Набор 0» на левой панели можно выбрать дополнительный продольный набор типа 0. В прежних файлах по умолчанию используется набор 0. Поддерживаются значения служебного флага профиля 0 и 1. У каждого профиля 32 байта заголовка, N записей точек по 60 байт и 132 байта служебных записей. XYZ — три little-endian int32 со смещением 32 байта внутри записи точки. Служебные координаты не добавляются в модель. Значения INT32_MIN/MAX отбрасываются как недопустимые.

Единицы отображаются **как в файле**: физическая единица не подтверждена спецификацией. Значения размеров — диапазоны координат, а не результат калиброванного измерения автомобиля.

Поверхность соединяет соседние профили, упорядоченные по X. Треугольники с ребром больше 250 единиц файла и вырожденные грани пропускаются. Это приближённая открытая поверхность: пропуски, невидимые сканеру части и днище не достраиваются. Для исходных измерений используйте режим точек. Вычитание Empty из Full и расчёт объёма не выполняются.

Пределы чтения: 512 МиБ, 5 миллионов точек. Производительность зависит от видеодрайвера и объёма данных. Для запуска нужен работающий системный OpenGL.

## Файлы Reference

Поддержан тип скана 3 (Reference): эталонные Cat3.bin, Cat7.bin и Cat22.bin. Тип Reference отображается в зелёной подписи. Используется тот же выбор пространственного и дополнительного наборов кнопками «Набор 1» и «Набор 0» на левой панели. Фотографии для открытия не требуются.

Проверены все три переданных файла: чтение, совпадение экспортируемых XYZ, обработка повреждённых записей, отрисовка точек и поверхности в x86 и x64. Cat3 и Cat7 содержат по 80 003 точки в основном наборе и побайтово идентичны (внутреннее имя Cat3, номер измерения 124). Cat22 содержит 96 915 точек (номер 156). Это свойства переданных файлов, а не подмена модели программой.

## Результат проверки

Дополнительные файлы проверены в x86 и x64: Основной набор БелАЗ 49 — 551 профиль и 75 643 точки; Cat7 — 625 профилей и 87 821 точка. Дополнительный продольный набор БелАЗ — 277 профилей и 153 072 точки; Cat7 — 314 профилей и 174 377 точек. Экспортированные XYZ точно совпадают с независимым чтением соответствующих групп BIN. Проверены обработка повреждённых записей, Unicode-пути и оба режима OpenGL.

Для первоначального Full: 211 профилей, 90 436 точек, 102 076 треугольников. Координатные диапазоны: X от −7000 до 5646, Y от −1163 до 2000, Z от 805 до 3901.

Проверки: точное совпадение экспортированных XYZ с независимым чтением BIN; индексы и длины рёбер граней; отбрасывание повреждённых файлов; отрисовка точек и поверхности OpenGL с сохранением кадров. Автоматическая визуальная проверка всего окна и системного диалога выбора файла недоступна: системный инструмент захвата окна возвращает `SetIsBorderRequired failed (0x80004002)`.

## Сборка из исходников

Использован [LLVM-MinGW](https://github.com/mstorsjo/llvm-mingw/releases/tag/20260922), пакет `llvm-mingw-20260922-ucrt-x86_64.zip`. Компилятор не нужен для запуска EXE.

Распакуйте компилятор и выполните в PowerShell:

```powershell
./build.ps1 -Toolchain 'C:/path/to/llvm-mingw-20260922-ucrt-x86_64'
```

Результат: `dist/Lase3DViewer.exe` (x64) и `dist/Lase3DViewer-Portable.exe` (x86). Скрипт также создаёт консольный проверяющий инструмент `build/inspect.exe`.

```powershell
python tests/test_reader.py 'D:/LASE/BinFiles/0000015068_Full.bin'
./dist/Lase3DViewer.exe --render-test 'D:/LASE/BinFiles/0000015068_Full.bin' 'D:/lase_scans/build/render'
```

Режим render-test создаёт два BMP-кадра, PLY и `render-ok.txt` либо `render-error.txt`, затем закрывает окно. Исходные BIN-файлы программа не изменяет и никуда не передаёт.
