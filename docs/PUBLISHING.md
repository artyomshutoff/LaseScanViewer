# Публикация LaseScanViewer

Текущая версия — 3.35.18. Репозиторий: [artyomshutoff/LaseScanViewer](https://github.com/artyomshutoff/LaseScanViewer). Релиз: [v3.35.18](https://github.com/artyomshutoff/LaseScanViewer/releases/tag/v3.35.18). Предыдущие выпуски сохраняются.

## Исходники и сборка

В репозитории находятся src/, tests/, scripts/, web/, assets/, docs/, README, build.ps1, app.rc, app.manifest, logo2.svg и прежние отчёты проверки. Сохраняйте встроенные заголовки, оценочную модель, src/vendor/ и лицензии сторонних компонентов.

Не добавляйте .tools/, build/, dist/, releases/, BIN, SQ3, points.npy и пользовательские настройки. Измерения пользователя не включены в репозиторий и релиз.

## Релиз 3.35.18

Содержит изменения 3.35.0–3.35.18: настройку веб-порта и короткий адрес сессии, автозагрузку парных сканов, исправления выбора Full/Empty и закрытия файлов, оформление панели и настроек, удаление выбора GPU, новый общий ракурс и автоматическое завершение веб-сервера после закрытия последней вкладки.

В Assets публикуются только семь файлов: Windows ZIP, четыре EXE, SHA256.json и Tests-summary.json. Исходники и README включены в Windows ZIP; GitHub также формирует архивы исходного кода автоматически. Для кнопки «Открыть в браузере» держите подходящий веб-EXE рядом с настольным.

Текущие проверки — Tests-summary.json внутри релиза. В 3.35.18 проверены сессии x64/x86 и браузер, а алгоритмы совмещения и объёма не изменены. Прежние отчёты INTERFACE-3.34-report.md, CONTROL-3.32-report.md и PERFORMANCE-3.31-report.md описывают проверки соответствующих версий, а не новый полный прогон.

При публикации обновите версию, исходники, README и описание релиза. Создавайте релиз сначала как черновик, загружайте проверенные файлы, сверяйте серверные SHA256 и лишь затем публикуйте. Не перезаписывайте прежние теги или релизы.
