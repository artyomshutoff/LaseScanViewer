# Подготовка к публикации на GitHub

README описывает версию 3.27.0. Исходники и документация находятся в репозитории, готовые EXE — в GitHub Releases.

Версия 3.27.0 содержит расширенное совмещение и проверку новых данных n-gk 2. Архив: `releases/LaseScanViewer-3.27.0-Windows.zip`; отчёт: `CONTROL-3.27-report.md`. Для следующих выпусков используйте новый тег и обновлённые результаты, сохраняя прежние выпуски.

## Содержимое репозитория

- `README.md`, `README-LaseScanViewer.md`, `docs/` и изображения из `docs/images/`.
- `src/`, `tests/`, `scripts/`, `assets/`.
- `build.ps1`, `app.rc`, `app.manifest`, `logo2.svg`.
- Нужные отчёты проверок, если вы хотите опубликовать соответствующие результаты и условия.

Сохраните встроенные заголовки и модель в `src/`, а также `src/vendor/` и сведения о лицензиях сторонних компонентов. Лицензия всего проекта не выбрана: определите условия распространения собственного кода и ресурсов перед публикацией.

Локальные `.tools/`, `build/`, `dist/`, архивы прежних выпусков, BIN-файлы, SQ3-базы и `points.npy` не нужны для чтения README или обычной сборки. Рабочие каталоги с измерениями не добавляйте в исходный репозиторий целиком; тестовые данные при необходимости публикуются отдельно.

## Выпуск 3.27.0

1. Обновите исходники, README, отчёт проверки и `docs/images/` в существующем приватном репозитории.
2. В **Releases → Draft a new release** создайте тег `v3.27.0` и название `LaseScanViewer 3.27.0`, укажите коммит этой версии.
3. Прикрепите `LaseScanViewer-3.27.0-Windows.zip`, оба EXE, архив исходников, `SHA256.json` и отчёты из каталога этой версии.
4. В описании укажите расширенный поиск совмещения, результаты на 344 контрольных парах и нерешённое максимальное расхождение; сохраните условия и ограничения проверки.
5. Проверьте отображение скриншотов README и доступность архива, затем опубликуйте выпуск.

Предыдущий выпуск: https://github.com/artyomshutoff/LaseScanViewer/releases/tag/v3.26.0. При следующих выпусках обновляйте номер версии и название архива.
